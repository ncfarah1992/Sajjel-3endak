# Sajjel 3endak · سجّل عندك

Card game scorebook for Leekha, 400, Tarneeb and Trex.

Database: run `supabase-setup.sql` in the Supabase SQL Editor (safe to run again).
After every phone has version 3.0 and has signed in once, run `supabase-lock.sql` to switch off the old code-only access.
(Running `supabase-setup.sql` again later re-opens it, so run `supabase-lock.sql` again afterwards.)
