# Sajjel 3endak

Card game scorebook, starting with Leekha. Works offline and stores all data on the phone (no sign-in).

Files: `index.html` (the app), `manifest.webmanifest` + icons (home-screen install), `sw.js` (offline support).
Host the folder on any static host (GitHub Pages, Netlify), open it on the phone, and choose "Add to Home Screen".
